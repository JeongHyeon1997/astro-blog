## 경력

### 주식회사 피트인 — 풀스택 개발자
**2025년 ~ 현재**

전기차 관련 서비스의 풀스택 개발을 담당하고 있습니다.

### (주) 씨엔티테크 — 프론트엔드 개발자
**2024년 3월 ~ 2025년**

푸드테크 도메인에서 1~10만 명 규모의 대형 프로젝트 신규 개발 및 유지보수에 참여했습니다. Front End PL 역할을 맡아 코드 품질과 개발 수준 향상을 주도했습니다.

**주요 프로젝트**
- **피자알볼로 리뉴얼** — Vue2 기반 Web/App을 React.js + React Native로 전면 리뉴얼
- **헥토 키오스크 오더인** — 키오스크 사장님용 Android App 및 관리자 Agent Web 프론트 1인 개발
- **미스터피자 Android App** — 유지보수 및 Android 버전 업, 라이브러리 교체, 코드 리팩토링

### (주) 픽셀 — 풀스택 개발자
**2022년 10월 ~ 2024년 1월**

창업 제안으로 합류하여 웹 개발, 앱 개발, 운영까지 전 과정을 경험했습니다.

**주요 프로젝트**
- **톡연구소** — Kotlin 기반 앱 개발, 유저 CS 대응 및 지속적 업데이트 운영
- **KPOP CHAT / 솔로채팅** — Next.js + Google Teachable Machine 기반 관상 테스트 컨텐츠, Google Analytics 퍼널 분석
- **마음드로잉** — 미술심리상담 Web 개발 참여 및 복잡한 프로젝트 QA 수행

### (주) 테라에너지 — 개발자
**2021년 10월 ~ 2022년 9월**

사내 ERP 서비스 개발에 참여하며 첫 프로덕트 레벨 경험을 쌓았습니다. 의왕시 한국전력 파견을 통해 데이터 웨어하우스를 경험하고 DB Query 역량을 향상시켰습니다.

**주요 프로젝트**
- **BI 내부 서비스** — HRM/ERP 내부 솔루션 개발 (Spring/JSP/jQuery → Vue2/Node.js 리뉴얼)

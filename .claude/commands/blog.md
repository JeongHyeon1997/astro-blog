# 블로그 글 작성 스킬

사용자가 블로그 주제를 제공하면 아래 절차에 따라 글을 작성한다.

## 입력

$ARGUMENTS

## 절차

### 1단계: 주제 분석 및 파일 생성

- 주제를 보고 적절한 카테고리 폴더를 결정한다 (frontend, backend, cloud, dev, log)
- 파일명은 주제를 영문 kebab-case로 변환하여 결정한다
- CLAUDE.md의 frontmatter 형식에 맞춰 파일을 생성한다
- `pubDatetime`은 오늘 날짜로 설정한다
- `.claude/skills/blog/TAGS.md`를 참고하여 기존 태그를 우선 재사용한다

### 2단계: 사용자 평문 수신 및 다듬기

사용자가 평문으로 내용을 작성하면 다음 규칙에 따라 다듬는다:

- **문체 유지**: 사용자가 쓴 말투, 흐름, 뉘앙스를 그대로 살린다. 딱딱하게 바꾸지 않는다.
- **구조 정리**: 제목 계층(`##`, `###`)을 잡고 자연스러운 단락을 구분한다.
- **코드 보강**: 사용자가 간략히 적은 코드가 있으면, 언어를 명시한 코드 블록으로 감싸고 필요하면 더 완성도 있는 예제로 보강한다. 단, 사용자가 의도한 범위를 벗어나는 코드는 추가하지 않는다.
- **불필요한 추가 금지**: 사용자가 쓰지 않은 내용을 임의로 넣지 않는다.

### 3단계: 이미지 처리

- 사용자가 `docs/` 폴더에 이미지를 넣어두면, 해당 이미지를 `src/assets/images/{글 주제}/` 폴더로 복사한다.
- 글 본문에서 이미지 파일명과 매칭되는 위치에 `![설명](../../../assets/images/{글 주제}/파일명.png)` 형태로 삽입한다.
- 사용자가 평문에서 이미지 위치를 언급하면 그 위치에, 아니면 문맥상 적절한 위치에 넣는다.

### 4단계: 태그 업데이트

- 글 저장 후 `.claude/skills/blog/TAGS.md`에 사용한 태그를 추가한다 (기존에 없는 태그만).

### 5단계: 커밋 및 푸시

- 글 다듬기가 완료되면 변경된 파일을 모두 커밋하고 원격에 푸시한다.
- 커밋 메시지는 `Add blog post: {글 제목}` 형식으로 작성한다.
